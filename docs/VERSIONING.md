# Version numbering

Current version: **0.8.53** (beta).

The project now uses the 0.x series. The historical releases use this numbering. Original Git commits and their ancestry will be retained. Milestones without preserved source remain documented only; no historical builds are invented.

Users of the previous numbering need one manual file replacement and reload. Do not uninstall if you want to retain local interests and settings. Old release and tag links may stop working after publication; automatic redirects are not guaranteed.
