# NostalgicTube 4.8.3 (beta)

Enjoy what it used to be. / Disfruta de lo que solía ser.

Current beta with automatic settings saving, a compact bilingual popup, official transparent branding and the donation footer.

- Local learning from searches and video-title keywords, with a reset and up to 10,000 interests.
- Continuous 0–100% Variety; Random ignores learned interests.
- No view-count threshold or popularity sorting in any feed mode.
- Native YouTube cards, progressive loading and duplicate prevention.
- Automatic retries with backoff and before: enforcement on YouTube searches.

Extract the attached ZIP, open brave://extensions, enable Developer mode and Load unpacked the NostalgicTube folder containing manifest.json. To update without losing learning, replace files in your existing folder and reload the extension and YouTube tabs.

Limitations: autoplay/Up next is still controlled by YouTube and may choose newer videos. Random samples search results, not the entire catalogue. Upload ages can be approximate. Internal YouTube changes, consent or throttling can interrupt loading. This is a beta, not a Chrome Web Store installation.

Historical source snapshots and documented-only milestones are explained in docs/HISTORY.md. The Git history was imported from preserved files, not fabricated original development commits.
