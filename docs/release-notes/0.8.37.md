# NostalgicTube 0.8.37 (beta)

- Use the 0.x version numbering consistently across the popup, main page, history and release notes.
- Add optional Nostalgic autoplay, disabled by default. At the end of a supported video, show the first eligible old recommendation inside the upper-right corner of the player with thumbnail, title, a 10-second countdown, Play now and Cancel.
- Confirm native YouTube autoplay is off before starting the countdown, and restore its previous state when this feature is switched off if NostalgicTube changed it.
- Cancel on navigation, hiding the tab, playback restart, candidate changes or disabling the feature. Do not run in playlists, live playback, ads, looping playback, fullscreen or picture-in-picture.
- Hide the before: operator from the visible YouTube search field while keeping the date cutoff in actual search URLs, including bookmark searches.
- Retain the eight-language discovery selector, calendar, interleaved random results and first-paint recommendation hiding.

Update: replace the files in your existing installation folder, reload the extension and reload YouTube. Keep the installation folder and do not uninstall to preserve local settings and interests. Users of the previous numbering need this manual replacement once; their installed update checker cannot learn the new numbering remotely.

Verification: 43 automated tests pass. Browser fixtures verify the autoplay card and clean search field. The user confirmed the player overlay in local YouTube; the 10-second adjustment and clean search field have automated checks. Historical releases have been renumbered consistently.
