# NostalgicTube 0.8.5 (beta)

Add a bilingual Check updates button that queries public GitHub releases on demand, including beta releases. Download links are restricted to the matching ZIP in this repository. Optional GitHub permission is requested only on a user click. Unpacked extensions still require replacing files and reloading manually; this does not silently install or execute remote code.

Keep the existing installation folder and do not uninstall to preserve settings and learned interests.
