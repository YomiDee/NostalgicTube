# NostalgicTube 0.8.50 (beta)

- Remove the manual More videos button and its duplicated idle text; keep automatic loading while scrolling.
- Retain the loading spinner, Loading more videos heading and playful messages only while loading or retrying.
- Center the home-page automatic-mix label when the notice about watching/searching to teach topics is displayed, aligning both lines.
- Remove obsolete button handlers so the page does not reference an element that no longer exists.

The Random generation method, date windows, request behavior and other features remain those of 0.8.37. The discarded local speed, cache and topic-learning experiments are not included.

Update: replace the files in your existing installation folder, reload the extension in brave://extensions, chrome://extensions or edge://extensions, then reload YouTube. Do not uninstall if you want to preserve local settings and interests.

Verification: 43 automated tests pass. The release ZIP is checked against every extension source file.
