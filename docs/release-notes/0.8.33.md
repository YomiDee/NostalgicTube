# NostalgicTube 0.8.33 (beta)

- Add an expandable discovery search language selector below Variety, with English, Spanish, Portuguese, French, German, Italian, Japanese and Russian.
- Enable all eight languages by default, save changes automatically and keep at least one selected.
- Apply the selection to discovery searches in mixed feeds and pure Random mode. Camera filename searches remain language-neutral; learned interests are unchanged.
- Localize the controls and explanation in English and Spanish.

This chooses the language of search terms, not a strict filter on the spoken language of videos. Random discovery remains search-based rather than a uniform sample of all YouTube.

Update: replace the files in your existing installation folder, reload the extension in brave://extensions, chrome://extensions or edge://extensions, then reload YouTube. Do not uninstall if you want to retain settings and interests.

Verification: 26 automated tests pass, including selected-language constraints and invalid-selection fallback. Real-browser visual confirmation is still pending.
