# NostalgicTube 4.8.21 (beta)

- Use dedicated horizontal recommendations on watch pages: 16:9 thumbnails on the left, title/channel/age on the right, with duration badges when available.
- Enlarge watch thumbnails by 10% relative to the first horizontal design.
- Hide YouTube's original watch recommendations and topic filters only after NostalgicTube has cards to show; restore them when disabled.
- Remove the loaded-video/discovery/scroll instruction counter.
- Show the automatic mix and discovery percentage on its own left-aligned line below the home toolbar.
- Keep the home feed's native YouTube renderer and avoid changing its thumbnail internals.

This release consolidates local iterations 4.8.14–4.8.21. The earlier thumbnail-sizing experiments were replaced before publication; they are not separate public releases.

## Update

Extract the ZIP into your existing installation folder, replacing its files, then reload the extension and YouTube tabs. Do not uninstall first if you want to preserve your local settings and learned interests.

## Verification and limits

13 portable tests pass, including horizontal card rendering, safe text handling, append behavior, source timeouts, date/mix/update logic and asset references. The horizontal layout was visually checked on a local fixture page; the user confirmed the layout in their YouTube session. This is not exhaustive testing of all YouTube layouts or Chrome/Edge versions. Autoplay/Up next remains controlled by YouTube and can select newer videos.
