# Asset provenance

The project owner supplied the official NostalgicTube logo and rounded triangular white-N icon during development. Transparent PNG derivatives were produced using image-editing tools and resized for the popup and Chromium icon sizes.

The source-code MIT notice is preserved. No separate third-party branding licence was supplied; this file records provenance rather than claiming exclusive rights or inventing an ownership transfer. YouTube/Brave/Ko-fi names and marks identify their respective services, not an endorsement.

Screenshots were captured from a separate test profile. The repository excludes original clipboard files, personal paths and the conversation transcript.
