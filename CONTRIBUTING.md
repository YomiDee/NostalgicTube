# Contributing

Open an issue with browser/version, extension version, language, cutoff, Variety value, expected behavior and reproduction steps. Do not post account data, cookies or private watch/search history.

Keep changes focused. Run the portable checks and perform the relevant manual checks in docs/TESTING.md. Preserve equal topic weighting, view-neutral selection, local-data boundaries, reset behavior and the explicit autoplay/random-sampling limitations.

The loadable source is in `extension/`. Do not edit archived ZIPs or rewrite imported release tags. Historical archives are retained as evidence, not supported deployment recommendations.
